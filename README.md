# mongoose -gray-image-server
是一个基于 Mongoose 嵌入式网络库开发的轻量级 HTTP 服务器，专为实时生成和传输 8 位灰度 BMP 图像 而设计。它运行于 Windows 平台，通过后台线程不断生成动态条纹与渐变混合的灰度图像，并通过 Web 界面实时预览，同时支持分辨率、刷新间隔的动态调整，以及简单的登录认证功能。
